The solution

Thin machines. Full renders.

WiCi One appears to each machine as a local GPU through the WiCi Driver. Interactive work stays responsive because the WiCi Protocol is built around a measured ~1.5 ms Wi‑Fi 6 round trip: viewports, timeline scrubbing, and previews run as they would on a desktop GPU, and exports run at desktop-GPU speed.

A studio on thin laptops. Each machine sees WiCi One as its own local GPU through the WiCi Driver, so the apps offload to it with no plugins and no changes.
