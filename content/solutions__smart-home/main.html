02 · Local memory

Process once.
Ask whenever.

WiCi processes supported camera and sensor feeds as events arrive. It records timestamps, objects, actions, and summaries in a local index that later questions can search directly.

Once Understand events when they happen instead of sending the same long recording through a model for every question.
Local Keep raw video, event summaries, and household context on hardware in the home.
Natural Ask about people, pets, rooms, and times in ordinary language instead of scrubbing through a timeline.
The WiCi approach

One local intelligence layer
for the whole home.

Connect the devices you already own to a full-size GPU nearby, then give applications permission to use the context they need.

Cameras and sensors produce observations. WiCi One runs multimodal models that turn those observations into timestamped events, descriptions, and searchable context. A question about the cat now uses the live feed; a question about yesterday searches the local event history first and retrieves the relevant moments.

The raw stream does not need to cross the public internet. Processing, storage, and retrieval stay on the premises, while the Overview, SDK, and APIs give home applications a path to the nearby GPU. The same compute can serve cameras, assistants, automations, and the other devices in the home.

Build on WiCi →

Context needs boundaries.

A capable home system should understand more while exposing less. Integrations, retention, and access remain explicit.

  • Connect supported devices. A camera or sensor must expose an authorized feed, event stream, or API.
  • Index useful events. Store structured descriptions and references to relevant clips instead of treating every query as a new scan.
  • Separate permissions. Each person and application receives access only to the rooms, devices, and history it needs.
  • Control retention. The household decides how long raw media and derived context remain available.

Integration scope

WiCi can add local intelligence only where a device exposes an authorized camera feed, event stream, or control API. Support therefore depends on the device and its integration. Households remain responsible for consent, access, and retention policies for people recorded in the home.
