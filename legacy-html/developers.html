SDK

Run PyTorch on wici.gpu.

Move the model and input tensor to the same device.

import torch
import wici
from torchvision.models import resnet50, ResNet50_Weights

weights = ResNet50_Weights.DEFAULT
model = resnet50(weights=weights).eval().to(wici.gpu)

preprocess = weights.transforms()
batch = preprocess(image).unsqueeze(0).to(wici.gpu)

with torch.inference_mode():
    prediction = model(batch)

FAQ

Questions about
building with WiCi.

Do I need to rewrite my app?
Often, no. Compatible clients can point to WiCi One’s OpenAI-compatible endpoint. The SDK is optional.
Does WiCi replace cloud AI?
No. Use WiCi for work that benefits from local latency, privacy, and control. Cloud services can still handle other tasks.
Does my data leave the network?
No. WiCi inference keeps prompts, audio, frames, and context on your local network.
Which models will be supported?
Preview examples include Kimi K3, DeepSeek V4.1 Flash, and Gemma 4 for language, FLUX.2 and Wan 2.2 for image and video, and Whisper for speech. Broader open-weight model support is in development. See how InferSSD runs 800B-class models →
