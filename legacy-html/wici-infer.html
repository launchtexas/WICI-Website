Measurement notes

InferSSD runs these 800B-class models without additional compression of the model files. Headline multiples show InferSSD throughput divided by the fastest supported competing engine in each model, hardware and metric panel, rounded to one decimal place. Chart values are tokens/s. Decode uses tokens 129–256 of a 256-token output. Bars use a common scale for the three engines on each system.

Results compare complete configurations. Mac DeepSeek uses Metal + CPU experts for GGUF engines and CPU-only Colibri with different weights and settings. Mac Muse uses a llama.cpp baseline with a different template and input length.

Questions about running LLMs locally

What is WiCi Infer?

WiCi Infer is a free desktop app that runs large language models locally. Discover open LLMs such as Qwen3.6, DeepSeek V4.1 Flash and Muse Spark Open, download them, and chat with them on your own computer. It is powered by InferSSD, our open-source local inference engine.

Which computers can run local LLMs with WiCi Infer?

Macs with Apple Silicon and Windows PCs (x64). Qwen3.6 35B runs with 8 GB of memory. 800B-class models such as DeepSeek V4.1 Flash start at 16 GB of memory and need about 520 GB of free SSD space. On Linux, use the InferSSD command-line engine.

How is WiCi Infer different from Ollama, LM Studio or llama.cpp?

Most local AI tools are built for models that fit in your computer’s memory, so very large models have to be compressed or do not run. InferSSD indexes the expert weights of mixture-of-experts models on your SSD and streams in the ones each token needs, so 800B-class models run without extra compression. In our benchmarks it reached up to 17.8x the decode throughput of llama.cpp on the same hardware.

Can I use a local LLM with Claude Code, OpenCode or my own apps?

Yes. WiCi Infer serves the loaded model through a local OpenAI-compatible API, so Claude Code, OpenCode and other compatible coding tools can use the same local model.

Do my prompts leave my computer?

The model runs on your own computer, so your prompts are processed locally instead of on a cloud AI service. There is no account or login.

Is WiCi Infer free?

Yes. WiCi Infer is free, with no subscription and no login. The InferSSD engine behind it is open source on GitHub.
