Fast over Wi‑Fi

Designed for
network latency.

T = Tlocal + N·RTT + D/Rate

Bandwidth matters. Blocking round trips matter more.

Local GPU software can make thousands of small calls with almost no network cost. A single vision-model inference issues roughly 20,000 user-mode driver calls;2 put a 1.5 ms wireless round trip under each one and the waiting alone runs ~30 seconds, for a job that finishes locally in under two. Even nvidia-smi, a status command, becomes ~800 round trips and runs 51× slower when remoted naively.2

WiCi reduces that call count. It caches stable facts, deduplicates repeated payloads, streams large transfers, and pipelines independent work. Expensive state stays on the box. Let only true dependencies block.

naive RPC 20,000 blocking calls · ~30 s of round-trip tax
WiCi runtime ~2,000, only true dependencies block2
483× median cost of a naively remoted driver call vs. local2
~1.5 ms measured Wi‑Fi 6 base round trip, the constant we engineer around2
10× fewer blocking calls once only real dependencies wait2

Fewer blocking calls. Less time waiting on the network.

Run bigger models

Models beyond
available VRAM.

Large open-weight models can exceed the memory of a single GPU. GLM-5.2 is 753B parameters, 330–425 GB even at 4-bit. DeepSeek-V4-Pro is 1.6T. Consumer DDR5 stops at 256 GB, and there is no socket that takes a fifth stick.3 NVMe provides the required capacity at roughly $0.10–0.20 per gigabyte, compared with $11–15 for shortage-priced DDR5.3

WiCi stores weights on NVMe and streams them to the GPU as needed.

VRAM 32 GB · ~1.8 TB/s · priced like it
DDR5 256 GB ceiling · ~90–100 GB/s · $11–15 / GB
NVMe multi-TB · ~14 GB/s rated · ~$0.15 / GB

NVMe provides the capacity. WiCi is designed to provide the speed.

Share one GPU

One GPU.
Many workloads.

CPUs schedule cycles

CPU time is renewable. A context switch saves a small amount of state in microseconds.

GPUs must schedule VRAM

GPU memory holds gigabytes of active state. Switching workloads can mean moving entire models.4

One machine may run an editor assistant, a CLI coding agent, a notebook kernel, a chat UI, each holding its own context, often loading the same base model into separate memory. WiCi One is built to schedule that pool at allocation granularity, so one cached copy can serve multiple devices and applications.4

Built for real time

Respond while input
is still arriving.

Local inference reduces delay in voice and interactive applications.

A voice system needs to know both what to say and when to say it. Our voice stack streams ASR in ~500 ms chunks, re-predicts an answer from the partial transcript, and runs a trained gate over every candidate. The gate costs ~0.02 ms, next to a ~140 ms answerer.5 Local processing keeps the microphone, model, and decision loop close together.

FAQ

Questions about
WiCi One.

What is WiCi One?
WiCi One is a dedicated GPU system on your local network. Nearby devices connect to it over Wi‑Fi and use the same shared compute.
How is it different from a cloud GPU?
WiCi One runs on your network, one hop from your devices. It avoids the public internet round trip and keeps local workloads under your control.
Is Wi‑Fi fast enough for GPU compute?
Not with naive GPU remoting. WiCi reduces blocking network calls through caching, deduplication, streaming, and pipelining. Performance still depends on the workload and network.
Can it run models larger than GPU memory?
That’s the goal of WiCi’s NVMe streaming system. Model weights stay on high-capacity storage and move to the GPU as needed. Performance optimization is still in development.
How can one GPU serve multiple devices?
Model weights load once and are shared. Each workload keeps its own private inference state, while WiCi schedules compute and GPU memory across devices.
What changes in my existing app?
Compatible clients can point to the OpenAI-compatible endpoint. The optional SDK adds discovery, pairing, streaming, and device control. Deeper runtime support is planned for supported GPU workloads.
Which workloads are a good fit?
Voice agents, robots, copilots, and local inference benefit from low latency and shared models. Workloads with frequent large transfers and readbacks may be better kept on the device.
Does my data leave the local network?
No. WiCi inference keeps prompts, audio, frames, and context on your local network.
Which models will be supported?
Preview examples include whisper-small, llama-3.1-8b-instruct, and piper-en-us. Broader open-weight model support is in development.
When is the Developer Preview?
